# Mohammed Baballah — developer portfolio

Independent personal portfolio for Mohammed Baballah Alsiddig Mohammed. The current layout fits the introduction, all three projects and entries for about, expertise and contact into one screen. Selecting a card or navigation button opens its content in a focused native dialog, while the overview blurs and dims. Close, Escape or a backdrop click returns to the overview and restores keyboard focus. The character, mood controls, page sections and their old styles have been removed.

The dashboard adapts to desktop, tablet, portrait phones and short landscape displays without page scrolling. Hovering or focusing a card flips it to a concise summary and blurs/dims everything else. On touch, tap once to preview and again for the full view; tapping elsewhere dismisses the preview. Enter/Space opens full details directly. Escape clears a preview or closes the focused dialog. Reduced-motion settings show the back face without 3D rotation. Detailed content may scroll inside its focused panel on smaller screens so text remains readable. Light/dark themes persist locally.

Owner preference: keep this project local. Do not upload or publish it without a new explicit instruction.

The studio finish uses a deep graphite palette, softer lavender/mint accents, translucent card surfaces, and a decorative ambient background built from CSS gradients, SVG contour lines and six subtle light points. All background graphics are hidden from assistive technology and never intercept input. The topbar motion button pauses/resumes background animation and persists only the preference (`mb-portfolio-motion`); background animation also pauses while the tab is hidden. System reduced-motion settings override the saved motion preference and remove the 3D card transition. No video, canvas loop, images or additional libraries are required.

The current glassmorphic skin is isolated in `dist/glass.css`: translucent frosted panels, backdrop blur, fine reflective borders, soft shadows and an aurora background visible through the surfaces. Dark mode uses deep blue glass; light mode uses pale frosted glass. Flip backs and focused views use stronger tint for readable text. A solid-surface fallback supports browsers without backdrop filtering. The prior skeuomorphic stylesheet has been removed. Dashboard geometry, flips, focus isolation, motion preferences and the contact workflow are preserved.

Page movement includes a slow 2-4px dashboard float, separately floating decorative project previews, and up to 5px of pointer parallax on desktop. Controls settle during card previews, focused dialogs and keyboard interaction. Pointer movement never applies on touch. The motion toggle controls both page and background; paused, hidden-tab and system reduced-motion states stop page movement. Pointer updates use one queued animation frame rather than a continuous JavaScript loop.
