# Mohammed Baballah — developer portfolio

Independent personal portfolio for Mohammed Baballah Alsiddig Mohammed. Dark olive and soft lime visual identity, responsive project illustrations, project category filters, accessible project-detail dialogs, mobile navigation and persistent light/dark themes.

Run with Node 24+: `npm start`, then open http://127.0.0.1:4330. Run `npm test` for source/server checks. The deployable static site is `dist/`; it needs no package installation or compilation.

Edit content in `dist/index.html` and project details in `dist/app.js`; theme and responsive styles are in `dist/style.css`. Project artwork is code-based illustration rather than actual application screenshots. Do not describe development goals as released features.

Contact currently links to the owner's confirmed GitHub account, https://github.com/Baballah2240. No email address, phone number, résumé, fabricated experience, client logos or testimonials have been added. A contact form/backend is not needed for this portfolio and is not included. This is a portfolio for a full-stack developer, not a new operational business application.

Sites publication starts owner-private. Public sharing is a separate audience setting. No Safeer, Stocrant or school-display runtime data is part of this site.
